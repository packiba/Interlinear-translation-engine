# Interlinear Translation Engine

Подготовка книг для читалки [bilingreader](https://github.com/packiba/bilingreader-v2):
парсер PDF, GPU-выравнивание предложений (LaBSE) между изданиями и сборка файлов BLB.

## Компоненты

| Файл | Назначение |
|------|-----------|
| `bl_book_parser.py` | PDF -> JSON с главами (оглавление, заголовки на странице, разрывы страниц) |
| `bl_sentence_aligner.py` | выравнивание предложений двух JSON; нужен CUDA |
| `bl_text_parser.py` | TXT -> JSON с главами (та же схема, что у парсера PDF); режим `--from-bilingual` берёт один язык из параллельного текста, где абзацы разных языков чередуются |
| `align_json_chapters.py` | сопоставление глав 1:1 двух разборов |
| `create_blb.py` | двуязычный BLB v1 |
| `process_book_pair.py` | вся цепочка для папки с двумя PDF |
| `multilang_sentence_aligner.py` | выравнивание нескольких языков: все пары напрямую, без опорного языка |
| `create_multilang_blb.py` | многоязычный BLB v2 |
| `find_book_editions.py` | поиск изданий книги на разных языках: только свободный доступ и только текстовые форматы (Wikisource, Project Gutenberg, Internet Archive); ничего не скачивает |

Подробности: `PIPELINE.md`, `PROCESS_BOOKS_README.md`.

## Результаты

Двуязычные книги (`books/ready/`, не в git): «Дети капитана Гранта» RU-BG, «Золотой жук» RU-BG,
«Маленький принц» RU-EN и RU-FR. Пара RU-BG «Детей капитана Гранта» плохо совпадает: это
разные издания.

Многоязычная книга: «Маленький принц» RU-EN-FR-ES-BG в одном BLB v2 (27 глав, 1062 строки,
1057 со всеми пятью языками). Метрики и ограничения — в `EXPERIMENT_V2_REPORT.md`.

## Поиск изданий

```bash
python find_book_editions.py --title "Дети капитана Гранта" --author "Жюль Верн" --title-lang ru
```

Правила: русский язык обязателен, и если свободного издания на нём нет, остальные языки не
ищутся (код возврата 2). Дальше по важности английский, болгарский, испанский, французский,
другие языки не ищутся (`--languages ru,en,bg,es,fr`).

Название на всех языках берётся из Wikidata, затем ищутся издания в Wikisource, Project Gutenberg,
Internet Archive (только вышедшие до 1930 года и не закрытые для выдачи) и, для болгарского, на
chitanka.info. Результат — число изданий на каждом языке и ссылки; ничего не скачивается. Полный
поиск занимает около минуты: запросы идут с паузами, иначе Wikimedia отвечает 429, а сбойные запросы
скрипт считает и сообщает. Для книг под защитой (например «Маленький принц») русского издания
обычно нет, и поиск на этом останавливается. Найденные тексты (TXT, EPUB, FB2, HTML) пока нужно
переводить в наш формат отдельно: парсер `bl_book_parser.py` читает только PDF.

## Известные проблемы

- Служебные главы изданий (обложка, послесловия) для многоязычной сборки указываются вручную
  (`--drop`).
- Настоящего N-мерного выравнивания (DP по всем языкам сразу) нет: попарные выравнивания
  сливаются в общие строки. Зернистость строк задаёт самый «крупный» язык.
