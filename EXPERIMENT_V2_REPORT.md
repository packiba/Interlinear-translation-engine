# Вариант 2: многоязычное выравнивание (RU-EN-FR-ES)

Дата: 2026-11-13. Книга: «Маленький принц», четыре издания (PDF в `books/MP_PAIRS/`).

## Как это работает

`multilang_sentence_aligner.py` берёт русский текст как якорь:

1. Для каждого языка запускается `bl_sentence_aligner.py` (src = RU, tgt = язык) со своей
   рабочей папкой. Сопоставление глав выравниватель делает сам, поэтому разное число глав
   в изданиях (RU 28, EN 31, FR 28, ES 23) не мешает.
2. Каждая пара находится в русском тексте книги (позиции символов без пробелов).
3. Строка общей таблицы — отрезок русского текста между «разрезами», которые не пересекает
   ни одна пара ни одного языка. Во всех колонках строка — один и тот же фрагмент книги.
4. `create_multilang_blb.py` собирает BLB v2: `multilingual_pairs` с текстом на каждом языке.

Служебные главы издания (обложка EN, новостная заметка 2004 года в EN, «À propos de cette
édition électronique» в FR) исключаются параметром `--drop` — иначе они приклеиваются к
последней строке книги.

Запуск:

```bash
D=books/MP_PAIRS/multilang_exp
python multilang_sentence_aligner.py $D/ru.json $D/en.json $D/fr.json $D/es.json \
  -o $D/multilang_aligned_sentences.json --drop en:1,30,31 --drop fr:28
python create_multilang_blb.py $D/multilang_aligned_sentences.json books/MP_PAIRS/RU_EN/mp-ru.pdf \
  -o $D/Malen_Prints_MULTILANG.blb --title "Маленький принц" --author "Антуан де Сент-Экзюпери"
```

## Результат

- 28 глав, 1172 строки; 1144 из них (97,6%) содержат все четыре языка.
- Покрытие русского текста парами: EN 99,6%, FR 99,2%, ES 98,1%.
- Сходство строк RU↔язык (LaBSE, косинус): EN среднее 0,74, FR 0,82, ES 0,75.
  Ниже 0,55: EN 70 строк, FR 23, ES 93 из ~1160.

Сами пары не менялись по сравнению с попарным выравниванием, поэтому качество строк
такое же, как у отдельных пар; строки стали крупнее (1172 против ~1480 пар на язык), потому
что разрез допускается только там, где согласны все языки.

## Ограничения

- Низкое сходство в основном из-за свободных переводов (особенно EN) и из-за разбора PDF:
  в испанском PDF начало книги обрезано («virgen: Historias vividas…»), а посвящения нет.
- Если на языке нет текста для строки, колонка пуста. Строки не удаляются, чтобы номера
  (и прогресс чтения в читалке) не зависели от выбранной пары.
- Заголовки глав других языков берутся только если похожи на заголовок (до 30 символов);
  иначе читалка показывает русский.
- Служебные главы приходится перечислять вручную (`--drop`).
- Истинного N-мерного выравнивания (DP по четырём языкам сразу) нет: используется слияние
  попарных выравниваний через русский. Выигрыш такого подхода не проверялся.
- В `create_blb.py` язык цели зашит как `bg` для всех книг, из-за чего в `books/ready/`
  у пар RU-EN и RU-FR в метаданных стоит неверный `lang_tgt` (исправить и пересобрать).
